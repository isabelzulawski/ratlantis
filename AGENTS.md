# Ratlantis interface preferences

Do not use decorative dots, bullets, middle dots, hyphens or dashes as separators in player-facing UI copy. Group information using spacing, line breaks, layout, or natural wording. This applies throughout the game and newspaper, including tooltips and labels. Preserve meaningful punctuation inside names, ordinary sentence punctuation, decimal points, data marks, and chart line patterns. Do not alter data values to enforce the copy preference.
